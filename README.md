# Assets needed by work.html

Export each layer from Figma (file `gLnZJLu3mV43buYTkKZgy5`) and save it under the name below.
Every `<img>` in work.html also carries `data-figma-node` so you can match it to the layer.

## Image crops
The CSS crops use the ORIGINAL (uncropped) image fills. If you instead export the rounded card
layer already cropped, add `work--exported` to `<main class="work">` and the crop values are ignored.
